# FlyWithAarav Website

A responsive static aviation / Microsoft Flight Simulator showcase site built with HTML, CSS and JavaScript.

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then save.
4. Wait for GitHub Pages to publish; the live URL appears on that Pages screen.

## Personalise it
- Replace the sample flight cards with your real videos and routes.
- Replace the Unsplash placeholder images with your own MSFS screenshots.
- Update the YouTube link if your channel URL differs.

This is a static site and does not require a backend or API key.
